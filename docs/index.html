An extension for Canvas to show modules on the side navigation panel.

How It Works

It is quite simple, it scrapes modules for each course and then displays it on the side panel where it should be. At first, it will force redirect you to the modules page (if you are not here already) but this is just so it can collect the data. It may also do this when data gets updated.

But Why?

I got annoyed of canvas not having this feature by default (how silly??) and so I ventured out to add it myself.
